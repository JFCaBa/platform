# What Platform on the web — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `https://whatplatform.uk` becomes the app's board in the browser (home with App Store badge, search, location, popular stations; `/station/{CRS}` live board), privacy moves to `/privacy`.

**Architecture:** Static files in `site/` (one `index.html` shell, `style.css`, ES modules under `site/js/`), served by nginx; the browser reads the existing API at `https://api.whatplatform.uk` (CORS for `https://whatplatform.uk`). Pure logic in small modules tested with `node --test`; rendering in `site/js/app.js`, checked by hand through a local dev server that proxies the API.

**Tech Stack:** HTML, CSS, plain JavaScript ES modules (no dependencies, no build), Node 26 built-in test runner, nginx, Python 3 (stats, dev server).

**Spec:** `docs/superpowers/specs/2026-11-25-web-design.md`

## Global Constraints

- No frameworks, bundlers, npm, build step, cookies, analytics scripts, third-party fonts or CDNs.
- No asking for location on page load: only when the user presses «Use my location».
- The web must not change what the installed apps get from the API.
- No Google Play badge. No following, push, widgets or Live Activities.
- App Store link: `https://apps.apple.com/gb/app/what-platform/id6835503942`; badge `site/app-store-badge.svg` (Apple's, unmodified).
- CSP: `default-src 'none'; script-src 'self'; style-src 'self'; img-src 'self'; connect-src https://api.whatplatform.uk; base-uri 'none'; form-action 'none'; frame-ancestors 'none'` — so no inline `<style>`, `style=""` or `<script>` anywhere (including `privacy.html`).
- Refresh every 30 s while the tab is visible; popular stations: EUS, KGX, PAD, VIC, WAT, LST, LBG, STP, CHX, MYB, BHM, MAN; recents: last 5 in `localStorage` (try/catch).
- Copy follows the app (`app/lib/ui/home_screen.dart`, `departure_row.dart`, `app/lib/domain/departure_text.dart`), English.
- Never store or log IPs, User-Agents or hashes (stats).

## Review Focus

1. Times across London midnight and BST/GMT: «23:58» seen at 00:03 is 5 min ago, not 23 h ahead — `minutesUntil` must use London clock (Intl `Europe/London`), tested in Task 2.
2. API failures in the browser (404 unknown at Darwin, 429, 502, network down, CORS): banner with «Retry» and the last board kept, never a blank page — owned by Task 3 (`fetchJson` error classes, tested).
3. `localStorage` throwing (Safari private mode, blocked storage): recents silently empty, page works — tested in Task 2 (`recents.js`).
4. A tab left in the background for hours: on return it refreshes at once and drops «Show more» pages that no longer follow on (`contiguousPages`) — Task 2 tests from the app's pages tests, Task 3 wiring.
5. Search input with accents, case, CRS codes and punctuation («st pancras», «KGX», «King's»): sensible top result — tested in Task 2.
